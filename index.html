Welcome aboard

This is the campaign hub for the archipelago pirate RPG. Three tools live here:

  • Character Sheet — each player tracks their own HP, Mana, and inventory, live-synced so the GM can see it too. Opens in a compact View mode by default, with a full editable mode for character creation.
  • GM Dashboard — a live overview of every character in one campaign, plus the ability to add new characters, adjust HP/Mana, and hand out player links.
  • Admin — every campaign and character across the whole project, for cleanup and finding a forgotten campaign ID.

Rules text lives separately (e.g. exported from Homebrewery) — link it here once it's hosted.

Quick start

GM: open the GM Dashboard first, create a character for each player, and send them their personal link. Everyone's changes sync live — no refresh needed.
