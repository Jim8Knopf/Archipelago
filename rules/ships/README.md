# Ship type pictures

Put a picture for a ship type here (e.g. `sloop.webp`, landscape works best) and add a line
under that ship in `../ships.md`:

    ![Sloop](ships/sloop.webp)

The Rules page shows it, the GM Dashboard shipyard shows it on the type card, and a ship
added from that type gets a copy of it (shrunk to 480×270, like an uploaded picture).
